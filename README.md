# Digital Banking System (C++)

A console-based digital banking system written in C++ that simulates ATM and basic online banking operations.

## Features
- Account creation and secure login
- Deposit and withdrawal with daily limits
- Fund transfer between accounts
- Transaction history tracking
- Persistent data storage using file handling
- Account lock after multiple incorrect login attempts

## Technologies Used
- C++
- File Handling
- Standard Template Library (STL)

## How to Run
1. Compile the program:
   ```bash
   g++ main.cpp -o banking
2. Run the program:
   ./banking
